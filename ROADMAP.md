# Roadmap

## Why keep going

Small in scope, but genuinely finished — deployed, offline-capable, polished down to wall-clock-aligned ticks and mobile rotation. That combination (small + actually done + shipped) is rarer in this account than the scope suggests it should be.

## What it opens up

The TODO already names the real next move: a visual retrospective of how the design evolved, pulled from git history (the clock apparently once offered a style picker before narrowing to one). The interesting part isn't the clock — it's that "turn a repo's git history into a shareable design story" is a repeatable format, not a one-off. This is just the first, cleanest case study for it.

## Capability this builds

Treating git history itself as material worth mining for a story, not just a changelog — directly useful anywhere a project has visibly evolved.

## Connects to

- **design-evolution** — literally built for this ("Evolve system design with Claude"); this clock is a ready-made first case study.
- **tcx2gpx** — the other small, genuinely complete, deployed site in the account; worth comparing what "finished" looks like in both.
